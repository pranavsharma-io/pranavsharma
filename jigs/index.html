What is JIGS Crypter?

A simple desktop app for encrypting files — no accounts, no internet, no fuss.

📁

Files & Folders

Encrypt a single file, multiple files, or an entire folder at once. Everything gets packed into one .jigs file.

How it works

Encrypting a file takes under a minute.

1

Add files or a folder

Click + Files to pick individual files, or + Folder to select an entire folder. All files inside the folder are included automatically.

2

Set your passwords

Type a password in the Passwords section. Click + Layer to add more passwords — each one adds a separate encryption layer on top.

3

Click Encrypt

Choose where to save the output. JIGS Crypter compresses and encrypts everything into a single .jigs file.

4

Decrypt anytime

Switch to the Decrypt tab, open the .jigs file, enter your passwords in the same order, and your original files are restored exactly as they were.

Multi-layer passwords, explained

Each password you add wraps the data in another encryption pass.

When you set 3 passwords, your data goes through 3 rounds of AES-256 encryption — one per password. To decrypt, all 3 passwords must be provided in the same order. If any one of them is wrong, decryption fails completely.

This is useful when multiple people share the encrypted file — each person holds one password and all must cooperate to decrypt. It's also simply stronger: an attacker would need to break all layers.

FAQ

Common questions.

What is a .jigs file?
It's JIGS Crypter's encrypted container format. It holds your compressed, encrypted file (or files), along with the information needed to verify and decrypt them. Only JIGS Crypter can open it.
What happens if I forget a password?
There is no recovery. AES-256 is designed so that data cannot be decrypted without the correct key. Keep your passwords somewhere safe — a password manager is recommended.
Can I encrypt multiple files at once?
Yes. Add as many files as you want using + Files, or use + Folder to include everything inside a folder recursively. All files are packed together into a single .jigs archive before encryption.
Do I need to install Python to use it?
No. The Windows download is a standalone .exe — just double-click and run. Python is only needed if you want to run from the source code.
Is the encryption strong enough for sensitive data?
Yes. JIGS Crypter uses AES-256-CBC with PBKDF2 key derivation (480,000 rounds of SHA-256) and HMAC-SHA256 for integrity. This is the same class of encryption used in professional security tools. The security of your data ultimately depends on the strength of your password.
Does the password order matter when decrypting?
Yes. If you encrypted with Password A first and Password B second, you must enter them in that same order when decrypting. If the order is wrong, decryption will fail.
